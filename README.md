AI Resume Coach

An AI-powered Resume Analyzer web application that helps users evaluate their resumes against job descriptions, identify missing skills, and improve their job readiness.

Features

- User Registration and Login
- Secure authentication using JWT
- Resume analysis
- Job Description matching
- Matching skills identification
- Missing skills identification
- Resume Match Percentage
- User Dashboard
- Credit-based usage system
- Analysis history
- PostgreSQL database integration

Tech Stack

Frontend

- React.js
- Vite
- JavaScript
- CSS

Backend

- Node.js
- Express.js
- REST API

Database & Authentication

- PostgreSQL
- JWT (JSON Web Token)
- bcrypt

How It Works

1. Create an account or log in.
2. Enter your resume content.
3. Paste the job description for the desired role.
4. Analyze your resume.
5. View matching skills, missing skills, and match percentage.
6. Use the dashboard to track your activity.
